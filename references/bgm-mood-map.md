# 配乐情绪映射方法论

## 选曲原则

1. **有台词的段落优先纯音乐/伴奏**。带唱词的歌会和人声抢清晰度，只在纯蒙太奇或情绪最高点用。
2. 同一情绪档至少准备 1 首 2 分钟以上的曲子，否则会频繁重复。
3. 曲库按情绪打标签，配置里只填标签（mood），不填具体文件——这样换曲只改一处。

## 情绪档位（本项目实际使用）

| mood | 情绪 | 典型剧情位置 |
|---|---|---|
| warm | 亲情温情 | 祭拜亲人、被收留、认亲、分给该分的人、团圆 |
| sad | 心酸憋屈 | 离别、被嫌弃、当免费保姆、寒心、被踢皮球 |
| cold | 寒心算计 | 抢房子、生日饭桌算计、当面虚伪 |
| drift | 孤苦漂泊 | 无家可归、雨夜街头、车站长夜 |
| grief | 悲愤爆发 | 被冤枉、当众受辱、掀底牌 |
| tear | 催泪震撼 | 寻亲、当街下跪、真相揭晓 |
| sob | 揪心绝境 | 病床前、读遗书、跪地痛哭 |
| punch | 反转打脸 | 儿子看傻眼、当众分钱、苦果自己尝 |
| light | 讽刺日常 | 上电视、假孝顺、群像插科打诨 |
| peace | 平静缓和 | 日常温情、犹豫、和解前 |
| hope | 升华治愈 | 食堂开张、好人好报、大结局 |

## 切点方法论

情绪段不能按固定间隔切，要挂在剧情节拍上。两级来源：

1. **集边界**（主）：data.ini 里每条记录带「第 N 集：标题」，31 个集标题天然就是切点。
   `manju init` 会自动把它们抽成 cue 骨架。
2. **集内节拍**（补充）：一集里出现明显转折时再加一个 cue，例如
   「被冤枉成贼 → 雨夜出走」「当众拆开棉袄 → 六十万现形」「读信 → 跪地痛哭」。

经验值：**38 个情绪段铺 53 分钟**，中位数 61s，最短 24s。
再密会出现「刚进情绪就换曲」，再疏就回到一首铺到底。

## 自动优化（引擎已实现）

- **相邻同情绪合并**：两个 cue 情绪一样就并成一段，避免同一首曲子被无意义地断开又淡入。
- **碎段回收**：短于 `minCueMs`（默认 20s）的 cue 并回上一段。
- **游标轮换**：同一首曲子在同一片里第二次出现时，从上次结束的位置继续播，
  而不是又从 0 秒前奏开始。

## 音量与包络

- 音量 `0.32`（台词在视频自带音轨里）。
- 段边界 0.7s 淡入 / 1.0s 淡出；同曲内部续接片段 0.15s 淡入淡出防爆音。
- 长段需要拼接同一首曲子时，第二片会从曲子的不同位置开始（游标），听感不会像单曲循环。
