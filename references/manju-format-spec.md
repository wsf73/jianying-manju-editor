# 爆款漫剧格式规范

## 轨道结构

```
tracks[0]  video        原片片段，不动
tracks[1]  text  "字幕"          台词字幕
tracks[2]  text  "人物出场介绍"   人物首次出场卡
tracks[3]  audio "配乐"          BGM
```

参考真实草稿 `晚晚非宝_#1_0`（1920x1080，1083 条字幕）与
`大雪长风_#1_0`（1080x1920，1067 条）反推得到。

## 字幕

| 项 | 1920x1080（横屏） | 1080x1920（竖屏） |
|---|---|---|
| 字体 | 新青年体.ttf | 同 |
| font_resource_id | 6740435892441190919 | 同 |
| 字号 font_size | 6 | 10 |
| 颜色 | 金黄 RGB(255,222,0) | 同 |
| 描边 | 黑 0.08 | 同 |
| 位置 y | -0.8 ~ -0.73 | -0.20 ~ -0.34 |
| render_index | 14000 | 14000 |
| line_max_width | 0.82 | 同 |
| letter_spacing | 0.05 | 同 |

要点：

- **只放台词本身**，不要带说话人名（人名靠人物出场卡解决）。
- 横屏字号 6 与竖屏字号 10 视觉大小等价（都按画布高归一）。
- 画面上字幕在哪一端由草稿的 transform.y 决定；实测同一台机器的横屏漫剧都在负值端。
  **人物出场卡放正值端**，与字幕分居两头就不会打架。

## 人物出场介绍

- 文案：`姓名 · 身份`，身份取 characters.json 的【身份】字段，按 `，,、` 取第一段，超 12 字截断。
- 样式：白字、字号 8、黑色 55% 圆角底衬（background_style=1, width 0.56, height 0.16, radius 0.35）。
- 位置 y = +0.55（与字幕相反端）。
- 时长 3s，同一条视频内多人首次出场错开 3.3s，起点比片段起点晚 0.4s。
- **跳过群体角色**：围观街坊 / 街坊群众 / 围观食客 / 记者群 / 村民们 这类没有姓名担当的，
  写进 config 的 `style.intro.skip`。

## 配乐

- 按 cue 表逐段换曲，不是一首铺到底。
- 段间 0.7s 淡入、1.0s 淡出；同一首曲子内部的续接片段各 0.15s 淡入淡出防爆音。
- 音量默认 0.32（台词在视频自带音轨里，BGM 要在人声之下）。参考草稿里纯音乐当主角时用过 2.412。
- 相邻同情绪的 cue 自动合并；短于 20s 的碎段自动并回上一段。
- 同一首曲子在整片里多次出现时，**从上次结束的位置继续**（游标轮换），避免每次都是同一段前奏。

## 时间轴的来源（重要）

字幕时间不是靠 ASR 猜的，是从字字动画工程的分镜直接算的：

```
字幕起始 = 该视频片段在剪映时间线上的 target_timerange.start
         + 该台词所在镜头在分镜里的 start（秒）
```

映射关系：视频文件名 `0001_<hash>_3_0.mp4` 的前 4 位数字 = data.ini 里第几条。
**必须按这个数字映射，不能按数组下标**——草稿可能缺号（本项目缺 0077、0230）。
文件名里的 hash 用来做校验，正常应 100% 匹配。

每条 AI 视频固定 12.25s，分镜计划总时长约 11~12s，
误差被单片段的 12.27s 容器吸收，不会跨片段累积。
